# Copy-and-paste Codex prompts

Use these in order from the repository root. Each prompt authorizes local implementation of its named milestone only. It does not authorize commits, pushes, publication, account changes, or unrelated deletion. A milestone blocked by missing tests/tools does not become complete by proceeding. The relevant documents are in the repository; you do not need to paste them all into chat.

## Recovery prompt - fix a failing milestone

```text
Read AGENTS.md and STATUS.md. Identify the current incomplete milestone and its
first failing or blocked gate. Reproduce the failure using the existing tests or
add a minimal regression test. Fix the root cause without changing intended
learning semantics, deleting tests, or adding hidden winning behavior. Rerun the
affected checks and production build. Record exact evidence and remaining blockers.
Do not advance to later milestones, commit, push, or publish.
```

## Resume prompt - continue in a fresh Codex session

```text
Read AGENTS.md, README.md, STATUS.md, PLANS.md, and the current milestone execution
note. Inspect the real tree and Git diff before editing. Summarize what is actually
implemented versus merely planned. Resume the next unfinished task inside that
milestone, preserve existing changes, and update the record with actual checks.
Do not rely on prior chat history or silently restart the whole implementation.
```

## Review prompt - independent verification without editing

```text
Review the current Echo Heist milestone in read-only mode. Read AGENTS.md, the
milestone gates, relevant contracts, and actual source/tests. Check especially for
hidden oracle access, fake learning, state aliasing, reward farming, evaluation
updates, stale worker results, unsafe imports, and project-base-path failures.
Report findings with file/line references, reproduction steps, severity, and the
specific acceptance criterion affected. Distinguish verified findings from risks.
Do not modify files, commit, publish, or claim checks you did not run.
```
