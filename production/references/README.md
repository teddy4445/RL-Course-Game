# Visual reference order

1. `../ART_CONTRACT.md` sets camera, grounded characters, anchors, naming and collision rules.
2. `AUTHORITATIVE_GAMEPLAY.png` is the implemented reference for scale, room readability and the minimal HUD. It is a starting quality bar, not a ban on improving the art.
3. The other running-build screenshots show the existing presentation and interaction surfaces. New work should improve coherence and polish rather than rebuild a different game.
4. `MOOD_ONLY_EARLY_SCREEN_CONCEPT.png` is optional inspiration for atmosphere and menu richness ONLY. Ignore its side-view platforming, floating/ghost Echo, mislabeled chapters, learning dashboards, arbitrary collectibles and instructional overlays. Do not crop it into runtime assets.

Runtime art is in `../../public/assets/`; the contact sheet is only for review. Full-scale assets for chapters 2-11 are not delivered. Future chapter art must reuse approved geometry or be created and validated before use.
