# Risk register and decisions that remain open

| Risk | Consequence | Mitigation / gate |
|---|---|---|
| Actual slides unverified | Topic ordering or algorithms may not match teaching | Keep proposed flags; owner alignment review; remap content before claiming verified course coverage. |
| Training too slow or unreliable | Player waits or cannot progress | Small MDPs, CPU-worker risk spike M04, bounded recipes, measured learning audits; redesign task instead of fake success. |
| Patch changes Echo's task mid-rollout | Invalid stationary-model assumptions | Independent lanes and explicit handoff/stage boundaries; state completeness tests. |
| Pretty interface hides fake learning | Educational premise fails | Numeric update fixtures, capability boundaries, frozen snapshots, negative controls. |
| 55 levels become repetitions | Boredom | Each brief includes a distinct player decision and failure mode; review within/across chapters during playtests. |
| UI becomes a dashboard | Breaks game-first constraint | At most two contextual dock controls; world-based feedback; no mandatory theory panel. |
| Latest dependency/examples mismatch | Broken renderer/worker/build | M00 exact version proof, lockfile, matching docs; no automatic major migration. |
| TFJS worker backend limitations | Neural chapters fail on some browsers | CPU baseline, small kernels, actual training probe, optional acceleration only after tests. |
| Save corruption or eviction | Student loses progress | Atomic generations, validation, previous snapshot, explicit export/import. |
| Import attacks/unbounded arrays | Memory exhaustion or unsafe execution | Closed schema and limits; no executable model topology/URLs. |
| Asset production incomplete | Game feels like a prototype | Explicit placeholder flags, prioritized asset manifest, final visual/audio gate. |
| Course data leaks | Password/slides accidentally public | No password in pack/runtime; no bundled unauthorized slide files. |
| Only convenient seeds tested | Misleading reliability | Frozen recipe and independent audit seeds, raw outcomes retained. |
| Public local scores mistaken for grades | False integrity assumptions | No secure grading claim; no leaderboard/account scope creep. |

## Defaults that permit development now

JavaScript rather than TypeScript application files; English; desktop keyboard-first; six Echo actions; grid simulation with interpolation; hash routing; one worker; one companion; local-only persistence; no service worker; original/procedural placeholders initially. These do not require another clarification to start M00.

## Owner decisions before final publication

Confirm lecture-slide mapping, especially Chapter 10 and the interactive imitation extension. Confirm actual repository/site path and publication authorization. Approve final art/audio and their rights records. Approve any changes to the 55-level scope or required hardware target. These are not reasons to block a local playable prototype.

## Engineering decisions to resolve with evidence

Exact dependency versions; feature vectors per task family; calibrated learning budgets; CPU versus an optional verified accelerator; supported browser minimums; actual transfer sizes; whether initial action latency warrants a faster tick. Record measured decisions and affected tests. Do not ask the user to choose numerical hyperparameters that should be established through implementation tests.
